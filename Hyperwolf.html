How this project is laid out. Every live app is one HTML file at the root; its screens live in a folder of the same name — pos/, pweb/ + promo/, athome/, delivery/, logistics/, mobile/, terminals/. Shared across all of them: pos/tokens.jsx (theme), pos/icons.jsx, pos/atoms.jsx, and shared/app-nav.js — the single nav list every left rail renders. Add an app there once and it appears in every rail.
