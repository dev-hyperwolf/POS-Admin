Concept C

Start from inventory, not from a form.

The operator sees the live batch list first — age, THC, on-hand, packaged/received date, never a Metrc tag — and checks the batches they actually want to move. The screen derives the narrowest condition set that covers exactly that selection, shown as loosenable chips, then the operator adds the reward, scope and window. "What else would this catch" surfaces any batch the derived rule also matches that wasn't selected, before it's saved.

Every condition below is a real RuleField/RuleOp pair from the contract. On-hand quantity is shown for triage but is not a targeting field — see the report for why.
