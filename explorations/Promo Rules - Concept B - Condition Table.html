The idea

The rule is a spreadsheet of conditions, and each row is checked against the batch list live, right there in the table.

ALL / ANY / NOT render as indented, labelled blocks instead of sentence connectors. The right-hand columns are the real per-batch pass/fail for each condition — computed in this page, not a canned screenshot — with the failing cell highlighted in red. A batch-only "Overall" row is also computed live; where a condition needs order or customer context this table doesn't have (channel, tier), it says so honestly rather than guessing. then / scope / window sit underneath as three compact cards, matching the shape's own three top-level keys.

Batch is the unit of control — batch.batch_no, THC, packaged/received date. No Metrc tag appears anywhere on this screen, by design (owner ruling, 2026-09-14).
