Reports — Concept A: Catalogue + Detail

R1 · reports:read/:pii/:export · reads GET /api/reports, /api/reports/{name}, /api/reports/{name}.csv
The idea

Browse the 12-report catalogue by category, run one, export it.

The left rail is exactly Blaze's own "Data Export" grouping — Overview, Manager, Sales, Inventory, Marketing, Compliance, Real-Time — so a manager who already knows Blaze's reports finds the same shape here. Selecting a report shows its own params (store, date range, and grouping for Sales Summary), runs it against the fixture data, and renders the same columns the server would send.

A locked row (PII) needs reports:pii — the Employee Activity report is scoped that way because it names employees. CSV export needs reports:export on top of reports:read. Switch roles top-right to see both gates.
