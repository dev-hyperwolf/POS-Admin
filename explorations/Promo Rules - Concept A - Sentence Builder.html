Promo Rules — Concept A: Sentence Builder

Team 1d · reads as English, edits as chips · hw.rule.v1 underneath
The idea

The rule is a sentence. Every chip is a real field pulled from a live cannabis inventory — never a made-up placeholder.

Each condition renders as one clause in a plain-English sentence. Clicking a chip opens a real RuleField/RuleOp dropdown — nothing on screen can express a value the contract would reject. "+ Add condition" appends a new clause to the sentence and to the JSON panel underneath it, live, so the two never drift apart. all / any / not read as sentence connectors (ALL / ANY / NONE) rather than as a tree.

Batch is the unit of control — batch.batch_no, THC, packaged/received date. No Metrc tag appears anywhere on this screen, by design (owner ruling, 2026-09-14).
